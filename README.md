# Deblockracy Updates

Releases of **Deblockracy** and the **Deblockracy Launcher** live here. The launcher reads this
repo's releases to find new game versions and to update itself, so there's no code here, just
releases.

## Install

Download **[Deblockracy-Launcher-Setup.exe](https://github.com/Ethandotpkl/Deblockracy-Updates/releases/download/launcher-latest/Deblockracy-Launcher-Setup.exe)**
and run it. It installs for you only (no admin prompt) and adds Start menu and desktop shortcuts.

Windows may say it protected your PC, because the installer isn't code-signed. Click
**More info**, then **Run anyway**. You only need to do this once: after that the launcher keeps
itself and the game up to date.

## What's here

- Game versions are releases tagged `v0.5.0`, `v0.6.0-preview.1` and so on. Previews are marked
  as pre-releases. Each release's description is that version's patch notes.
- The launcher's own updates are in the `launcher-latest` release.
